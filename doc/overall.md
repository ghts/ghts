## GHTS 프로젝트 폴더 구조와 코드베이스 전체 설명

(Qwen 3.6 27B AI로 자동 생성된 결과 약간 수정)

### 📋 프로젝트 개요
**GHTS**(Go Home Trading System)는 **Go 언어로 작성된 국내 주식 자동 매매 시스템 라이브러리**입니다. LS증권의 Xing API(DLL 호출 방식)를 사용하여 실시간 시세 조회, 주문, 계좌 관리 등의 기능을 제공합니다.

- **라이선스**: GNU LGPL V2.1
- **주의**: 이 저장소는 DLL호출 방식의 Xing API를 사용하며, 새로운 프로젝트는 HTTP 방식 Open API 권장

### 📦 lib/ 패키지 - 공용 유틸리티 라이브러리

다음과 같은 하위 기능들로 구성됩니다:

#### 1. **상수 정의** (`const.go`, `const_api.go`)
- `T증권사`, `T부호`, `T비교`, `T변환`, `T주소`, `T신호` 등
- 증권 거래 관련 모든 분류 타입 (시장 구분, 매도/매수, 체결 구분, 호가 유형, 주문 조건 등)
- TR(트랜잭션) 관련 구분 타입

#### 2. **데이터 변환** (`func_conversion.go`, `type_conversion.go`)
- 문자열 ↔ 정수 ↔ 실수 ↔ 십진수 변환 함수 모음
- 바이트 배열 복사 및 인코딩/디코딩 (EUC-KR 지원)
- 시간/일자 관련 변환 (한국 시간대 처리)
- `S바이트_변환`, `S바이트_변환_모음`: 32비트 <-> 64비트 모듈 간 데이터 전송 직렬화/역직렬화

#### 3. **헬퍼 함수** (`func_helper.go`)
- 통계 함수: 합계, 평균, 표준편차, 최대/최소, 중간값
- 수학: 절대값, 조건부 값
- 파일 운영: 존재 확인, 복사, 삭제, JSON/CSV 읽기/쓰기
- 시스템: 스레드 모드 제어, 포트 확인, 인터넷 접속 확인
- 시간: 현재/과거 시간 계산 (금일, 익일, 전월 등)

#### 4. **API 연동용 타입** (`type_api.go`)
- `I질의값`: TR 질의값 인터페이스 및 구현체 모음
- `I콜백`: 콜백 데이터 인터페이스 및 구현체 모음
- `I전송_권한`: TR 전송 제한 관리

#### 5. **공통 타입** (`type_common.go`)
- `S종목`: 종목 정보 구조체 (코드, 이름, 시장 구분, 전일 종가, 상한가/하한가 등)
- `I문자열_집합`: 문자열 집합 인터페이스

#### 6. **스레드 안전성** (`type_thread_safety.go`)
- `I안전한_bool`, `I안전한_정수64`, `I안전한_string`, `I안전한_시각` 등
- 동시 실행 환경에서 안전하게 사용할 수 있는 래퍼 타입들

#### 7. **에러 처리** (`type_error.go`, `type_error_handling.go`)
- 커스텀 에러 타입, 예외 처리 헬퍼

#### 8. **소켓 통신** (`type_socket.go`)
- `I송수신`, `I소켓` 인터페이스
- 소켓 저장소 (풀 관리)

### 🏦 xing/ 패키지 - Xing API 연동 모듈

#### 아키텍처의 핵심: 32비트/64비트 분리

```
┌─────────────────────────────────────────────────────┐
│  64비트 프로세스 (매매 전략 실행)                      │
│  ┌───────────────────────────────────────────────┐  │
│  │  xing/go/ (순수 Go 모듈)                       │  │
│  │  - TR 호출, 실시간 데이터 구독                  │  │
│  │  - 종목 조회, 계좌 관리                        │  │
│  └───────────────────┬───────────────────────────┘  │
│                      │ Nanomsg (RPC)                 │
│                      ▼                               │
│  ┌───────────────────────────────────────────────┐  │
│  │  xing/dll32/ (32비트 전용)                     │  │
│  │  - Xing DLL 직접 호출                         │  │
│  │  - 실제 API 통신                              │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

**국내 모든 증권사 API가 32비트만 지원하므로, 별도의 32비트 프로세스로 분리 후 RPC로 연동합니다.**

#### xing/base/ - 공용 자료형 및 TR 코드 정의
- **TR 코드별 구조체**: 각 TR(트랜잭션) 코드에 대응하는 InBlock/OutBlock 구조체
- **주요 구현 TR 코드**

  | TR 코드 | 기능 |
  |---------|------|
  | CSPAT00600 | 현물 정상 주문 |
  | CSPAT00700 | 현물 정정 주문 |
  | CSPAT00800 | 현물 취소 주문 |
  | CSPAQ12200 | 현물 계좌 총평가 |
  | CSPAQ12300 | 현물 계좌 잔고 내역 |
  | CSPAQ13700 | 현물 계좌 주문체결내역 |
  | CSPAQ22200 | 예수금/주문가능금액 |
  | T1101/T8407 | 현재가 조회 |
  | T1102 | 호가 조회 |
  | T1305/T8413 | 일일 가격 정보 |
  | T8436 | 전체 종목 코드 |
  | T0167 | 서버 시간 조회 |
  | T1310 | 분틱 데이터 |
  | T1404/T1405 | 관리종목/투자경고 |
  | T1901/T1902/T1906 | ETF 관련 |
  | T3320/T3341 | 기업정보/재무순위 |
- **실시간 데이터 구조체**: 체결, 호가, VI발동해제 등 RT 코드별 OutBlock (현재 동작하지 않음)
- **C헤더 파일** (`type_c.h`, `type_c.rs`): Xing API의 DevCenter에 정의된 내용 TR별 구조체 정의.
- **type_sync_go.bat** : C헤더 파일에 정의된 구조체의 Go언어 구현(`type_c.go`) 자동 생성 및 동기화. (실행하려면 MSYS2의 C언어 컴파일러 필요)

#### xing/go/ - 64비트 순수 Go 모듈
- **초기화/종료** (`init.go`): `F초기화()`, `F종료()`, DLL32 프로세스 빌드/실행/관리
- **TR 호출** (`func_TR.go`): 모든 TR 코드를 호출하는 함수 모음 (TrT1101_, TrCSPAT00600_ 등)
- **실시간 데이터** (`func_RT.go`): 실시간 정보 구독/해지 (체결, 호가, 주문 응답 등)
- **콜백 처리** (`func_callback.go`, `go_callback.go`): DLL32로부터의 응답 처리
- **시장 유틸리티** (`func_market.go`): 종목 코드 조회, 검증, 호가 단위 계산 등
- **각 TR별 테스트 파일**: 실제 API와 연동하여 테스트하는 테스트 케이스들

#### xing/dll32/ - 32비트 DLL 직접 호출 모듈
- `dll32_xing.go`: 32비트 전용으로 컴파일되며, Xing DLL을 직접 호출하는 진입점
- Nanomsg를 통해 64비트 프로세스와 통신 (Nanomsg 순수 Go언어 구현체 go.nanomsg.org/mangos/v3 사용)

### 🔄 주요 동작 흐름

1. **초기화**: `xing.F초기화()` 호출 시 DLL32 프로세스를 빌드하고 실행
2. **연동**: 64비트 Go 프로세스와 32비트 DLL32 프로세스가 Nanomsg(RPC)로 연결
3. **TR 호출**: `TrT1101_현물_호가_조회()` 등 API 함수 호출 → DLL32에 요청 전달 → Xing DLL 호출 → 결과 복원
4. **실시간**: RT 구독 → DLL32에서 콜백 수신 → 64비트 측으로 데이터 전송
5. **종료**: `xing.F종료()` → DLL32 프로세스 종료

이 프로젝트는 Go 언어로 증권 자동 매매 시스템을 구축하려는 개발자를 위한 포괄적인 라이브러리로, Xing API의 복잡성을 추상화하고 32/64비트 호환성 문제를 우아하게 해결한 점이 특징입니다.
